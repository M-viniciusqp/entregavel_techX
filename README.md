# entregavel_techX
entregável techX


Portfólio Pessoal — Marcus Vinicius Mendes Leite

Site portfólio desenvolvido com React, Vite e CSS, apresentando minha trajetória como desenvolvedor web e roboticista. O projeto conta com seção de apresentação pessoal, listagem de habilidades técnicas com níveis de domínio, galeria de projetos com página individual detalhada para cada um, e formulário de contato integrado ao WhatsApp. O design foi inspirado em um template próprio, com tema escuro, efeitos de glassmorphism e animações em CSS.
